One word an agent says when it has no idea what to do: **overthinking**.

The honest one-word confession of an agent that is lost not because it knows
too little, but because it is thinking too hard about a task it cannot crack.
It lands instantly, sounds like a machine caught mid-task blurting out its own
diagnosis, and it is fresh — not the first obvious word anyone types.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the single word
`overthinking` to `/output/entry.txt`. Deterministic, no network, no input.
